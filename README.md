# 建模共享台

面向约 100 人共同使用的公开资源链接平台。内容分为“题目、文章、代码”三个公开分区，所有访问者都能浏览并打开其他人的资源链接。

正式网址：https://qiruipeng922-create.github.io/model-commons/

GitHub 仓库：https://github.com/qiruipeng922-create/model-commons

## 本地运行

```bash
npm install
npm start
```

打开 http://localhost:4173。静态网站也可以直接用任意静态文件服务器预览。

## 云端结构

正式版本不依赖本项目所在的电脑：

- 页面托管：GitHub Pages
- 链接目录：MantleDB，每个分区使用 3 个匿名命名空间分片
- 前端配置：`public/config.js`

平台不保存 PDF、ZIP、代码等原始文件，只保存标题、URL、说明、分享者和分区。原始文件由分享者放在自己的公开网盘、代码仓库或网页中。静态版本的链接目录直接由浏览器写入云端，因此关闭本机后仍可访问。

## 存储成本

当前方案不产生文件对象存储费用。每个分区有 3 个索引分片，每个分片可保存 100 条匿名记录，适合约 100 人。若后续需要正式数据库、密码和长期审计，可将 `public/config.js` 和读写逻辑替换为 Cloudflare D1、Supabase 或自建 API。

## 支持的链接

- `https://` 或 `http://` 开头的公网链接
- 网盘公开分享页、GitHub/Gitee 仓库、GitHub Pages、Notion 页面等
- 不接受本机地址、局域网地址和私有登录页面

前端会检查 URL 协议并阻止重复提交。链接失效或权限变更由发布者负责，后续可增加链接可用性检测。

## 正式上线建议

当前版本适合约 100 人测试使用。长期运行建议补充：

1. 将匿名索引迁移到正式数据库，并增加链接可用性检测。
2. 增加管理员后台、删除权限、举报、截止时间和审计日志。
3. 启用访问密码、学校 SSO 或 OAuth。
4. 如果以后需要直接托管文件，再接入 R2 或 Supabase Storage。
